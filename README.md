# Sinal Verde Da Obra

Simulador de viabilidade para construção financiada pela Caixa: a partir do crédito, do terreno e do custo real da obra, calcula a área que cabe no orçamento, todos os custos (cartório, taxas, juros de obra e prestação) e gera uma proposta clara para o cliente, que pode ser enviada por link.
